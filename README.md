Installation and Files

This repository provides two main ways to use SSTAR:

SSTAR_installer.exe: A standalone, user-friendly version of SSTAR with a graphical user interface (GUI). 
The installer includes the required MATLAB Runtime, allowing the application to run independently 
without a MATLAB license. This option is recommended for most users, particularly those interested in 
applying SSTAR without modifying the code.

SSTAR_v1.mlapp: The MATLAB App Designer version of SSTAR, developed in MATLAB R2021b. This version is 
intended for users with MATLAB (preferably R2021b or compatible versions) who wish to explore, adapt, 
or extend the underlying code and methodology.

An example dataset demonstrating the use of SSTAR is available on Zenodo 
(https://doi.org/10.xxxx/zenodo.xxxxxxx)). Due to its size, it is not hosted directly on GitHub.

Quick Start:

Option 1 — Standalone application (recommended)
- Download SSTAR_installer.exe from this repository.
- Run the installer and follow the instructions (this will also install the MATLAB Runtime if needed).
- Launch SSTAR from the installed application.
- Download the example dataset from Zenodo.
- Load the dataset within the GUI and run the analysis.

Option 2 — MATLAB version (for advanced users)
- Download SSTAR_v1.mlapp.
- Open the file in MATLAB (R2021b or later recommended).
- Run the app from the MATLAB environment.
- Download the example dataset from Zenodo.
- Use the dataset to test and explore the workflow, or adapt the code to your needs.

Notes
The standalone version is designed for ease of use and does not require programming experience.
The MATLAB version provides full flexibility for customization and methodological development.
A stable internet connection is recommended when downloading the example dataset from Zenodo.
